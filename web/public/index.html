Computing this grid

    Add your machine

    Anything that runs Docker such as a laptop, Pi, NAS can compute a section. Add it with one command, no configuration needed.

    Your section appears here within a few seconds. Stop it with docker rm -f life. Up to 2 engines per address.

    Each outlined region is one engine's 7×7 section of a single shared grid. Faded regions are catching up. Dashed boxes are free slots. Hover a name to find its section; click a section to reseed it.
