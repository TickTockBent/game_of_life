What You're Seeing

This is Conway's Game of Life split across a set of independent engine containers. Each colored section of the grid is owned by one engine, which computes only its own 7×7 cells. Engines never talk to each other: before every step each one asks the controller for a one-cell “halo” of its neighbours’ border cells, so patterns flow seamlessly across section boundaries as if it were one grid. A central controller uses barrier synchronization to keep every engine on the same generation — it broadcasts a step only once all engines have reported in (or a one-second timeout expires). Engines can be added or removed at any time; the grid simply grows or shrinks. It currently runs as a Docker Compose stack on a single home-lab server, but the same code ran across a multi-node Kubernetes cluster, and nothing in the design assumes the engines share a machine.
